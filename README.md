# cavanaug.vmware

Omarchy bar plugin for VMware Workstation. Lists the library and runs power/guest actions via `vmrun`.

Installed as a symlink:

```text
~/.config/omarchy/plugins/cavanaug.vmware → ~/wip_other/src_cavanaug/cavanaug.vmware
```

Validate with `omarchy plugin validate ~/.config/omarchy/plugins/cavanaug.vmware`.
Self-check: `node check.js`.
